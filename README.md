# Superstore Sales: Business Intelligence & Performance Dashboard

 📌 Project Overview
This project transforms a raw dataset of over **9,900 retail transactions** into a dynamic Business Intelligence tool. The objective was to clean unstructured data and build an interactive dashboard to track **$2.29M in revenue** and identify key profit drivers across the United States.

 🛠️ Data Engineering & Analysis Techniques
To ensure high-quality insights, the following data workflows were implemented:
* **Data Parsing & Cleaning:** Utilized **Text-to-Columns** for data standardization and performed **Deduplication** to ensure 100% data integrity.
* **Data Synthesis:** Developed multi-dimensional **Pivot Tables** to aggregate sales by Category, Region, and Product Manager.
* **Dynamic Visualization:** Engineered **Pivot Charts** and integrated **Interactive Slicers**, allowing users to filter performance by Year, Region, and Segment in real-time.

📊 Key Business Insights
* **Revenue Milestone:** Analyzed a total of **$2,297,462.82** in sales with a total profit of **$286,438.94**.
* **Top Performers:** Identified **Technology** as the leading category (36.4% of total sales), with **Phones** ($330k) and **Chairs** ($328k) driving the highest revenue.
* **Managerial Analytics:** Tracked performance across 17 Product Managers; identified James Marez (Phones) and Sandra Cruz (Chairs) as top-tier contributors to the firm's growth.
* **Temporal Trends:** Analyzed sales cycles from **2014 to 2017**, identifying seasonal peaks to assist in inventory forecasting.

 🚀 How to Use this Project
1. Clone the repository.
2. Open the file in the `Dashboard/` folder using Microsoft Excel.
3. Use the **Slicers** on the right side of the dashboard to filter data by Region or Category.
4. Observe how the Pivot Charts update automatically to reflect the filtered business metrics.
